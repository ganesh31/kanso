# Brainstorming wireframes

These are the HTML fragments shown on the design board while the V1 spec was being agreed (`docs/superpowers/specs/2026-11-19-kanso-breakout-scanner-design.md`, §7.5 "wireframes agreed in brainstorming"). The board supplied the styling, so opened directly in a browser they render unstyled, but they're still readable.

- `breakout-definition.html`: the four breakout shapes and seven quality factors considered
- `breakout-recommendation.html`: the V1 starting set (N-year high plus four filters)
- `system-builder-mockup.html`: System Builder, Scanner and Stock Report wireframes
- `rzone-vs-kanso.html`: RZone's System Builder flow (redrawn from Definedge's public help article) compared with Kanso's
